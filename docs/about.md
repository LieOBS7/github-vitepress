## 想参与？

欢迎大家一起完善这个文档站，但请遵守以下几点：

- 📝 **想补充内容 / 新建页面**：完全没搞过也没关系，一步步来：

  1. 打开仓库 https://github.com/LieOBS7/github-vitepress ，右上角点 **Fork**（第一次会让你点"Create fork"，直接点就行）
  2. 进你自己的 Fork（地址变成 `github.com/你的用户名/github-vitepress`），点进 `docs/` 文件夹
  3. 右上角点 **Add file → Create new file**
  4. 文件名写 `你的标题.md`（比如 `python笔记.md`），后缀必须是 `.md`
  5. 内容用 Markdown 写就行，不会写？开头打个 `# 标题`，下面直接打字跟写记事本一样
  6. 拉到最底下，Commit changes 那栏写一句"加了xxx页面"，点 **Commit changes**
  7. 回到你 Fork 的首页，等几秒会弹一个 **Contribute → Open pull request** 的黄色提示条，点它
  8. 点 **Create pull request**，标题随便写，点 **Create pull request** 完事

  之后我看到就会合并，合并完你的内容就出现在我的文档站里了，你的头像也会出现在贡献者列表 🫠

- 🚫 **请不要修改** `config.ts`、`deploy.yml`、`package.json` 等配置文件，这些是我自己维护的
- 🐛 **发现哪里写错了 / 有问题想问**：直接去 [GitHub Issues](https://github.com/LieOBS7/github-vitepress/issues) 提，看到了会回
- 💡 **有想加的话题**：也可以在 Issue 里说，我考虑要不要写

## 技术栈

本站用 [VitePress](https://vitepress.dev/) 搭建，Markdown 写文档，推到 `main` 分支自动通过 GitHub Actions 部署。
