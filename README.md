# 神人忧天の文档

> 用 Markdown 写，推一次 main 就上线。

一个基于 VitePress 搭建的静态文档站，部署在 GitHub Pages 上。

## 在线访问

https://LieOBS7.github.io/github-vitepress/
或
https://my.srytdocs.nx.kg/

## 技术栈

- VitePress — 静态站点生成器
- Vue 3 — 前端框架
- GitHub Actions — 自动构建部署
- GitHub Pages — 托管

## 本地开发

npm install
npm run docs:dev

然后访问提示的本地地址（默认 http://localhost:5173/github-vitepress/）


## 目录结构

docs/
├─ index.md          # 首页
├─ about.md          # 关于
├─ start.md          # 快速开始
└─ .vitepress/
   └─ config.ts      # 站点配置
